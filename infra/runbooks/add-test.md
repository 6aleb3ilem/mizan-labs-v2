# Runbook — Add a test (no release)

1. Admin console → Catalog → Test definitions → New definition: inputs, computed values,
   aggregates, rules, stages, intake fields, report columns.
2. Sandbox with sample data until the computed values and rule outcomes are right.
3. Activate the version (formulas are validated before activation).
4. Create the service (kind LAB_TEST, unit of sale) and its price in the branch price list.
5. The test appears in the generated laboratory menu and in the quote builder.
