# Runbook — Add a tenant

1. Platform console → Platform → Tenants → New tenant (code, name, plan).
2. The tenant admin is invited (e-mail with a temporary password, MFA enrolment at first login).
3. The tenant admin runs the setup wizard: departments → units → natures → definitions →
   services & prices → templates → numbering → workflows → roles → users.
4. Signing keys for the first branch are created (KMS in production, local files in dev).
