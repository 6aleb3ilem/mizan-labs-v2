# Runbook — Add a branch

1. Admin console → Organisation → Branches → New branch (identity, currency, taxes, timezone,
   working days, locales) — or clone the configuration of an existing branch.
2. Numbering schemes, signatories, treasury accounts and print profiles for the branch.
3. Signing keys for the branch (rotate-signing-key runbook, steps 1–3).
4. Memberships of the branch staff.
