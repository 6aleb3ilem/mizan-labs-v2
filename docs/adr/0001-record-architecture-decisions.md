# ADR 0001 — Record architecture decisions

Date: 2026-09-11 · Status: accepted

## Context
`docs/SPEC.md` v2.2 fixes the product and architecture. Decisions taken while building that
refine or deviate from the specification need a durable, reviewable record.

## Decision
Every such decision is an ADR in `docs/adr/`, numbered, with context, decision and
consequences. The specification is only changed by issuing a new numbered version.

## Consequences
Deviations are visible to reviewers; the specification stays the source of truth.
